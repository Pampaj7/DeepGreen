\newcommand{\DataAvailabilityStatement}{%
All data and code underlying this study are public in the replication package at
\url{https://github.com/Pampaj7/DeepGreen}; an archived copy with a DOI will
accompany the published version. The package contains the implementations for
all \vEcosystems{} ecosystems, the shared measurement bridge, the experiment
specification and its conformance checker, the campaign driver, the per-block
dual-instrument records for all \vRuns{} runs and \num{\vBlocks} blocks, and the
analysis pipeline that turns those records into the tables, figures and quoted
numbers in this manuscript. The saturation cell's records --- the same per-block
dual-instrument readings, per-epoch metrics, run manifests and data fingerprints
for its \vSatRuns{} runs, with the excerpt of the utilisation record that covers
them --- are in a directory of the package of their own, built by the same
pipeline and never merged with the campaign's. A single command regenerates the
manuscript from the raw records, so every number here can be traced to the
measurement it came from, except where stated; \ESMname{} lists the
exceptions (Sects.~\ref{app:repro} and~\ref{app:collapse}).%
}

\newcommand{\GenerativeAIStatement}{%
During the preparation of this work the authors used generative AI assistants
(ChatGPT and Claude) in three distinct capacities, which we separate because
they carry different weight.

For \emph{writing}, the tools were used to improve the readability of the
manuscript text. For \emph{software engineering}, they were used to repair and
refactor the experimental implementations, to write the shared measurement
bridge, the conformance checker and the analysis pipeline, and to diagnose
defects in the ecosystems' data loaders and build configurations. For
\emph{analysis}, they were used to write the scripts that produce the tables and
figures; the scripts, not the assistants, produce the numbers, and the numbers
are injected into this manuscript from those scripts rather than transcribed.

No experimental measurement was produced, adjusted or selected by an AI
assistant. The authors reviewed and edited all generated content and code,
verified the findings against the raw data, and take full responsibility for the
content of the article.%
}
